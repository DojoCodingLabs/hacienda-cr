# SDK repository audit and 0.11.0 release assessment

Audited on 21 October 2026 against main `a90efca`, with comparison to the
published `v0.10.0` source and live npm metadata. This is a repository/release
audit with an inventory and dependency/scope assessment of open PRs; it is not
a line-by-line approval of every open proposal.

## Release decision

A release is needed: reviewed PR #107 is merged but npm `latest` still points
to 0.10.0 for all four packages. Changesets' linked-group plan selects 0.11.0
for shared, SDK, CLI and MCP, including the CLI's linked minor bump. Use Git tag
`v0.11.0` on the reviewed version commit and npm dist-tag `latest`.

The release contains the merged v4.4 compatibility work, its two review
regressions and the existing response-verifier adversarial regression added
after 0.10.0. Exact API supported cases stay unchanged. Recalculate stored
mixed-tax totals as described in the SDK migration guide. Open PRs below are
excluded from this release.

## Current SDK boundaries

- HTTP authentication/response reads retain deadlines and cancellation;
  authenticated redirects are rejected, and mutations are not retried by default.
- Signing and response verification retain bounded inputs, pinned native
  verification and adversarial tests; schema-valid signatures alone are not trust.
- Legacy Number calculations now carry the merged specific-tax fields, preserve
  taxability when positive-rate taxes round to zero and preserve existing
  non-rate IVA validation. The CLI interactive draft still uses Number/parseFloat
  ([issue #61](https://github.com/DojoCodingLabs/hacienda-cr/issues/61)).
- Exact REP monetary projection, recipient transport/correlation, legal
  qualification and live acceptance remain unresolved broader work
  ([issue #85](https://github.com/DojoCodingLabs/hacienda-cr/issues/85)).
- Schema provenance, native XSD conformance, exact arithmetic oracles, transport
  tests and fresh packed consumers are release checks; none establishes fiscal
  acceptance or authorizes application activation.
