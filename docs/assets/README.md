# Banner de Hacienda CR

`hacienda-cr-banner.png` se generó con la herramienta integrada de imagegen para este repositorio. Referencia visual: [dojocoding.io](https://www.dojocoding.io/), inspeccionado el 3 de octubre de 2026 (Archivo, fondo `#F1F1F9`, tinta `#201E3D` y coral `#FF7151`).

## Prompt final

Use case: ads-marketing
Asset type: wide GitHub README banner, approximately 3:1 landscape
Primary request: Design a beautiful polished open-source toolkit banner for Hacienda CR using Dojo Coding's current dojocoding.io visual branding.
Scene/backdrop: pale lavender #F1F1F9, deep ink #201E3D outlines, coral orange #FF7151 accents, subtle peach panel.
Style/medium: crisp editorial graphic design, bold Archivo-like sans-serif typography, playful geometric star accents, thin dark outlines and offset solid ink shadows inspired by the Dojo Coding website.
Composition: generous margins, title left, a simple stylized invoice/document with code brackets and checkmark right. Small Dojo Coding wordmark upper left accompanied by a circle in a pink-to-coral gradient containing a white Japanese torii gate motif. Clear visual hierarchy; professional developer toolkit identity.
Text (verbatim): "Dojo Coding", "Hacienda CR", "Facturación electrónica para Costa Rica", "SDK / CLI / MCP", "OPEN SOURCE · TYPESCRIPT"
Constraints: all text legible and spelled exactly, one uncluttered cohesive banner, no extra slogans or tiny pseudo-text, no photo, no watermark. Artwork should remain legible at GitHub README width.

## Logo oficial

`dojocoding-mark.png` es el archivo oficial descargado de [dojocoding.io](https://www.dojocoding.io/assets/brand/dojocoding-mark-256.png), usado como referencia de inserción para el banner y directamente en el pie del README.

La edición final se hizo con imagegen y los dos archivos de entrada: el banner original y el logo oficial. Prompt final de edición: reemplazar únicamente el círculo torii de la esquina superior izquierda por el logo oficial, conservando su degradado coral a lavanda, viga curva y proporciones; mantener el wordmark y todo el resto del banner sin cambios.
