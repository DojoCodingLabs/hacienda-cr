# Costa Rica civil holidays — 2026

Dates transcribed from MTSS CARTA-MTSS-DAJ-AER-1076-2025, page 1:
https://www.mtss.go.cr/temas-laborales/feriados/feriados_calendario_2026.pdf

The original PDF is preserved here with a manifest hash. The JSON is a derived,
reviewed transcription, not a byte-identical download. All twelve dates are kept
on their listed dates. No Monday-transfer rule or future calendar is inferred.
The SDK embeds the JSON, returns copies, and rejects years outside 2026.

This is a civil work calendar. It does not establish a fiscal deadline, exceptional
administrative closures, employer-specific rest days or a legal infringement.
Callers must independently establish the applicable deadline and start event.
The source PDF can be checked with pdftotext; updating a year requires reviewing
an official source and adding regressions before changing the bounded coverage.
